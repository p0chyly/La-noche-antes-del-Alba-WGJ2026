# Información Técnica
El proyecto fue programado en Godot 4.7.2 usando GDscript.
Los modelos 3D fueron creados en Blender y Autodesk Maya.
Todo el arte visual en 2D fue hecho en Adobe Photoshop, Krita, Clip Studio Paint.
Las animaciones 2D fueron creadas con Adobe After Effects.
La planificación de la historia y el formato en novela visual fue hecho en Twine.
